## Description

You run a crane in a scrapyard and a storm is coming in. Slide the trolley, lower the cable, line up the blue ring with a piece, switch on the magnet and lift. Then carry it to the container while the cable swings and the wind pushes.

The view is three-quarter, so there is depth too: Q and E move the trolley between three lanes. If the ring is not on the piece, the magnet will not hold it. Heavy things slip. Drop one in the wrong place and you will hear about it from yourself.

This is a prototype. It is small on purpose and I want to see if the crane feels good to run before building more around it.

## Controls
- Left / Right (A / D): move trolley
- Up / Down (W / S): cable down / up
- Q / E: depth lane
- Space: magnet on / off
- R: restart
